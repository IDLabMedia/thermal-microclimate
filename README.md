# Thermal UAV imaging and pollinator diversity

This repository contains the source code and data accompanying the paper:

**"Thermal UAV imaging to assess microclimate variation as a contributor to pollinator diversity, generated through biodiverse mowing management in mesic grasslands"**

## Contents

* `notebooks/` — Jupyter notebooks containing the analyses.
* `data/` — Data used and derived by the notebooks. Some data are included in the repository, other needs to be downloaded (see below).

### Additional data

The contents of `data/local/` are not included in the repository due to their size. Download the additional data (0.5 GB) from:

**[Download the additional data](https://cloud.ilabt.imec.be/index.php/s/NK3bPnesz3xST8Y)**

After downloading, unpack the archive into the `data/` directory so that the files are available under `data/local/`.
